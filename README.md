# Delivery — تطبيق المحل (Flutter)

نفس قاعدة بيانات Firebase التي يستعملها الموقع delivery-dz.pages.dev وتطبيقا الزبون والموصّل.
كل رفع للكود على GitHub يبني ملف APK تلقائياً ويضعه في صفحة **Releases** باسم `Shop-N.apk`.

- الطلبات: جديدة / تحضير / جاهزة / السجل، قبول ورفض، «جاهز للموصّل»، «سلّمته للموصّل».
- رنين متكرر ما دام هناك طلب جديد لم يُقبل، ويعمل والشاشة مطفأة ما دام المحل مفتوحاً.
- توزيع الطلب على أقرب موصّل متصل يتم من هاتف المحل (نفس منطق الموقع).
- المنتجات مع الصور والأحجام والإضافات، العروض والكوبونات، إعدادات المحل (الغلاف، الموقع، الساعات).
- إشعار في الهاتف للطلب الجديد يضيء الشاشة ويظهر فوق القفل، ويختفي عند القبول أو الرفض، وإشعار عندما لا يوجد موصّل متاح.
- المبيعات: مستحقات اليوم وآخر 7 أيام في أعمدة، متوسط الطلب، الأكثر طلباً في 30 يوماً، وما زال عند الموصّلين.
- وقت التحضير: عدّ تنازلي على كل طلب قيد التحضير مع تنبيه عند التأخر، وزر «+10 د» يُبلغ الزبون ويحدّث وقت الوصول عنده.
- اقتراب الموصّل: بُعده ووقت وصوله على بطاقة الطلب، وتنبيه عندما يصل إلى المحل.
- شريط «لا يوجد اتصال بالإنترنت» عند انقطاع الشبكة، وشريط «نسخة جديدة متاحة» مع زر تنزيل مباشر.
- منتجاتي: بحث بالاسم أو القسم، مرشّح «متوفر / نفد»، وعناوين للأقسام.
- الإعفاء من تحسين البطارية: شريط «اسمح للتطبيق بالعمل في الخلفية» حتى لا يقطع الهاتف عنه الشبكة فتتأخر التنبيهات.
- تنبيه بالصوت والإشعار عندما يُلغى طلب جديد أو قيد التحضير.
- مع الشبكة الضعيفة لا تعلق الأزرار: يُحفظ التغيير فوراً ويُرسل عند عودة الاتصال.
- يومياتي وإعلاناتي (في تبويب العروض): يوميات بصورة تختفي بعد 24 ساعة، وإعلانات لمدة يختارها المحل، يراها الزبائن في صفحة المحل.
- آراء الزبائن (من تبويب المبيعات): المتوسط، توزيع النجوم، والتعليقات.
- المبيعات: عدد زبائن آخر 30 يوماً، منهم الجدد ومن عادوا للطلب.
